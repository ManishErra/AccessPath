# UI Design Guide

## Brand
**AccessPath**  
Tagline: **Know before you go. Report what you find.**

Create an original text-based wordmark and simple path/pin/accessible-route-inspired icon. Do not use the official LPU logo.

## Visual system
- Primary: deep navy/indigo
- Accent: accessible teal
- Background: warm off-white or very light neutral
- Surfaces: white cards with subtle borders
- Text: high-contrast charcoal/navy
- Status colors: distinct but not color-only; always include text labels/icons.

## Layout
- Desktop: centered max-width content, clear hero search, two-column sections where useful.
- Mobile: single column, full-width controls, compact nav/menu, no horizontal overflow.
- Cards: clear hierarchy for location, category, date, status, description.
- Forms: one column, labels above inputs, helpful hints, inline errors.
- Use consistent spacing and button styles.

## Accessibility requirements
- WCAG-minded contrast.
- All controls keyboard reachable.
- Visible focus ring.
- Semantic headings and landmarks.
- Form labels programmatically associated with controls.
- Error summary or inline errors that are announced.
- Do not communicate status using color alone.
- Respect reduced-motion preference.
- Images need alt text; decorative icons hidden from screen readers.
- Use readable font sizes and generous touch targets.
