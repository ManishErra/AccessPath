# Suggested Classroom Demo Script

1. Open the AccessPath home page.
2. Explain: “This is a prototype for searching user-reported accessibility barriers by block or keyword. It does not use GPS or require a complete campus map.”
3. Search “B34” and open the sample lift-related record.
4. Point out the Sample label, report date, status, and unverified notice.
5. Search “ramp” to show keyword matching.
6. Submit a new fictional demo report, clearly identifying it as a class demonstration.
7. Open My Reports and show that it is stored on this browser/device.
8. Open Demo moderation and change a report status.
9. Explain the limitation: local storage only; no real university staff receive reports.
10. Close with future scope: verified building-wise facility directory, official collaboration, cloud backend, moderation, and accessible route information.

Do not present fictional seed data as actual observations or interview evidence.
