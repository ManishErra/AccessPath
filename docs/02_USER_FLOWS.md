# User Flows and Screen Inventory

## Main navigation
Home | Search | Report an Issue | My Reports | About  
A “Demo moderation” entry may appear in a clearly marked prototype menu.

## Flow 1 — Search a location
1. Open Home.
2. Enter a block/building or issue keyword (e.g. “Block 34”, “B34”, “Block 33”, “lift”, “ramp”).
3. Submit with button or Enter.
4. View matching reports.
5. Apply status/category filters.
6. Open a report to view details.
7. Read the date, status, and unverified-report notice.

## Flow 2 — Report an issue
1. Select “Report an accessibility issue”.
2. Enter location/block.
3. Add optional precise location detail.
4. Select issue category.
5. Enter title and description.
6. Optionally attach a photo.
7. Select how the reporter knows about it.
8. Confirm the privacy/safety checkbox.
9. Submit.
10. Show confirmation and a link to view the new report.

## Flow 3 — My Reports
1. Open My Reports.
2. See reports created in this browser/device.
3. Open any report.
4. Optionally delete a local report after confirmation if this feature is built.

## Flow 4 — Demo moderation
1. Open Demo moderation.
2. Select a report.
3. Change status.
4. Add optional note.
5. Save.
6. Show updated status and append a history event.
7. Clearly remind user that this is local demo data only.

## Required pages
- Home/dashboard
- Search results
- Report detail
- Submit report
- My Reports
- Demo moderation
- About/how it works
- Not found / empty states
